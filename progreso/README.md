# 📈 progreso/ — Lo que llevas

La IA lee estos archivos al empezar cada sesión para **retomar donde lo dejaste** y los actualiza al cerrarla (`/cerrar` o diciendo *"terminamos"*).

| Archivo | Para qué |
|---|---|
| `diario.md` | Una entrada por sesión: qué hiciste y qué toca después |
| `errores.md` | Tus errores frecuentes y cómo evitarlos — **léelo antes de cada examen** |
| `dominio.md` | Semáforo de cada tema: ⚪ sin evaluar · 🔴 no lo domino · 🟡 con ayuda · 🟢 solo y sin errores |

> En Claude.ai / ChatGPT la IA no puede escribir archivos: al terminar te dará el texto para que lo pegues aquí. Luego vuelve a subir los archivos actualizados al proyecto.
